# Capacity Connect

Capacity Connect is a local Flask-based learning management and capacity-building portal. It supports role-based access for trainees, trainers, and administrators, plus courses, resources, assessments, certificates, and competency mapping.

## Project structure

```text
Capacity_Connect/  Application code, templates, static assets, database, tests, and outputs
requirements.txt   Python dependencies
LICENSE            MIT License
```

## Run locally

1. Install Python 3.11 or later.
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:

   ```bash
   cd Capacity_Connect
   python app.py
   ```

Open `http://127.0.0.1:5000` in a browser. On Windows, you can also run `Capacity_Connect\run.bat`.
